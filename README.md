# Bangla Store

Bangla Store is a modern, visually stunning eCommerce frontend built specifically for traditional and modern Bengali products. The application is built using Next.js, React, and Tailwind CSS, focusing heavily on providing a premium user experience and beautiful design aesthetics.

## Key Features

- **Modern UI/UX**: Designed with dynamic animations, glassmorphism, and a vibrant color palette to ensure an engaging customer experience.
- **Responsive Layout**: Fully responsive, working smoothly across mobile, tablet, and desktop views.
- **Fast Performance**: Leveraging Next.js App Router and server-side rendering where applicable to deliver rapid loading times.

## Tech Stack

- **Framework**: Next.js 16+
- **Styling**: Tailwind CSS, Lucide React (for icons)
- **Language**: TypeScript

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `/src/app`: Contains the routing structure and pages of the web app.
- `/src/components`: Reusable UI components used throughout the platform.
- `/src/data`: Mock data or static resources for testing.
- `/src/context` & `/src/types`: TypeScript definitions and React context providers.

## Deployment

You can deploy the app easily via Vercel or any Next.js compatible hosting platform.
